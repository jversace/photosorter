# PhotoSorter

Application Android de scan et tri de photos.

## Description

PhotoSorter permet de scanner tous les fichiers images présents sur un téléphone Android (stockage interne et carte SD), de les visualiser, les trier, les filtrer et d'effectuer des actions sur ceux-ci.

## Prérequis
- Android 8.0 (API 26) minimum
